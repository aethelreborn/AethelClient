# AethelClient

A clean, smooth, glassmorphic Fabric client mod for Minecraft 1.21.11.

## Features

- Glassmorphism ClickGUI with smooth open/close animations, live search and animated setting cards
- Optimized 2D rendering pipeline (batched, layered strata) and 3D world render pipelines
- Keybind module system with configurable bindings, colors, sliders, modes and text settings

## Building

AethelClient builds with Gradle on Java 21. CI (GitHub Actions) builds every push and publishes jars to GitHub Releases automatically — you never need to build locally.

```bash
./gradlew build
```

The built mod jar ends up in `build/libs`.
